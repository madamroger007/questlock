# QuestLock Roadmap

This document defines the planned evolution of the QuestLock platform.

The roadmap exists to guide development priorities and prevent uncontrolled feature expansion.

AI agents must use this document to determine implementation priority.

Do not implement future-phase features unless explicitly requested.

---

# Roadmap Principles

QuestLock should be built incrementally.

Core productivity enforcement systems must be completed before secondary features.

Always prioritize:

1. Product Enforcement
2. Core User Experience
3. Reliability
4. Analytics
5. Advanced Features

Never prioritize advanced features before the enforcement system is complete.

---

# AI Agent Instructions

Before implementing a feature:

1. Identify the roadmap phase.
2. Verify feature status.
3. Verify feature priority.
4. Verify dependencies.

Rules:

- Complete current-phase priorities first.
- Do not skip foundational systems.
- Do not implement future-phase features without approval.
- Do not invent roadmap items.

Roadmap order should guide implementation priorities.

Product Vision always takes precedence over roadmap expansion.

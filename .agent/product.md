# Product Vision

This document defines the product vision, business purpose, and core principles of QuestLock.

All features, systems, and implementation decisions must align with this document.

If a proposed feature does not support the product vision, it should be rejected or reconsidered.

---

# Product Identity

Product Name:

QuestLock

Category:

Productivity Enforcement Platform

Core Purpose:

Help users complete productive work before accessing distracting or entertainment applications.

QuestLock is designed to create accountability through enforced productivity, not passive task tracking.

---

# What QuestLock Is

QuestLock is:

- A Productivity Enforcement Platform
- A Focus Accountability System
- A Mission-Based Productivity System
- A Reward-Driven Access Control System
- A Digital Self-Control Tool

QuestLock actively controls access to entertainment applications based on user productivity.

---

# What QuestLock Is NOT

QuestLock is NOT:

- A Todo App
- A Habit Tracker
- A Project Management Tool
- A Note Taking Application
- A Calendar Application
- A Team Collaboration Tool
- A Generic Productivity Dashboard
- A Gamification App

These features may exist as supporting systems, but they are not the product itself.

---

# Core Product Philosophy

Productivity must be completed before entertainment is granted.

Users earn access to entertainment through productive work.

The system should encourage discipline through accountability, not motivation alone.

The product should actively enforce rules rather than simply track behavior.

---

# Core User Problem

Users often:

- Procrastinate by opening games
- Get distracted by entertainment applications
- Lose focus during productive work
- Lack accountability for unfinished tasks

Traditional productivity applications only track behavior.

QuestLock enforces behavior.

---

# Core Product Loop

Every major feature must support this loop:

Mission
→ Focus Session
→ Mission Completion
→ Reward Earned
→ Gaming Credits Granted
→ Entertainment Access Unlocked
→ Credits Consumed
→ Mission Required Again

This loop is the heart of the product.

If a feature does not support this loop, reconsider its value.

---

# Primary Systems

The following systems are considered core systems.

---

## Mission System

Purpose:

Define productive work that must be completed.

Examples:

- Study
- Coding
- Writing
- Work Tasks

Missions are the foundation of productivity enforcement.

---

## Focus Session System

Purpose:

Measure productive work.

Focus Sessions may be:

- Timer Based
- Application Tracked
- Activity Based

Focus Sessions provide proof of productivity.

---

## Reward System

Purpose:

Convert productivity into rewards.

Supported rewards include:

- XP
- Coins
- Gaming Credits

Rewards must always originate from productive work.

---

## Gaming Credit System

Purpose:

Control entertainment access.

Gaming Credits are earned through completed productivity requirements.

Gaming Credits are consumed when entertainment access is granted.

Gaming Credits are the primary enforcement currency.

---

## App Guard System

Purpose:

Enforce access restrictions.

Responsibilities:

- Monitor applications
- Detect blocked applications
- Validate access rights
- Consume Gaming Credits
- Block unauthorized access

App Guard is the enforcement engine of the platform.

---

# Secondary Systems

Secondary systems exist only to support the core loop.

Examples:

- Analytics
- Monitoring
- History
- Notifications
- User Settings
- Device Management

These systems should never become the primary focus of development.

---

# Product Success Metrics

The product is successful when users:

- Complete more missions
- Spend more time in focus sessions
- Reduce entertainment usage during work hours
- Increase productivity consistency
- Build sustainable productivity habits

---

# Product Design Principles

Every feature should follow these principles:

1. Productivity First
2. Enforcement Over Tracking
3. Simplicity Over Complexity
4. Accountability Over Motivation
5. Rewards Must Be Earned
6. Entertainment Must Be Controlled
7. Focus Must Be Measurable

---

# AI Agent Instructions

Before implementing any feature:

Ask:

1. Does this support the Core Product Loop?
2. Does this improve productivity accountability?
3. Does this strengthen productivity enforcement?
4. Does this help control entertainment access?

If the answer is NO:

Reconsider the implementation.

Do not add features that turn QuestLock into:

- A Todo App
- A Habit Tracker
- A Project Management Tool
- A Social Platform

QuestLock is a Productivity Enforcement Platform.

This principle takes priority over feature expansion.
